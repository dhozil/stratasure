# StrataSure Frontend

Next.js frontend for the StrataSure GenLayer parametric insurance protocol.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

Configure `NEXT_PUBLIC_CONTRACT_ADDRESS` after deploying `StrataSure`.

## Development

```bash
npm run lint
npm run build
```

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- GenLayerJS
- TanStack Query
- Radix UI
